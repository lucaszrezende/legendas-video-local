# Legendas Vídeo Local

Transcrição profissional, 100% no seu Mac — timestamps por palavra, pausas,
ênfases e emoções na voz. Sem internet, sem conta, sem rastreio.

Antes chamado **Whisper PRO**. O instalador da versão 0.13.0 ainda usa o nome
antigo.

Este repositório hospeda apenas os instaladores (Releases).

## Requisitos

- macOS 26 (Tahoe) ou mais recente
- Mac com chip Apple (M1 ou mais novo)

## Instalação

Baixe o `.dmg` na [página de releases](../../releases/latest), abra e arraste
o app para Aplicativos (na versão 0.13.0 ele aparece como **Whisper PRO**).
Na primeira abertura, o macOS pede confirmação em **Ajustes do Sistema →
Privacidade e Segurança** (o app está em processo de notarização pela Apple).
